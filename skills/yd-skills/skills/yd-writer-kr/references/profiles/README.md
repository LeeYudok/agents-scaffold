# 표기 프로필 작성법

프로필은 조직마다 다른 표기 규칙을 담는 Markdown 파일이다(#137).
이 폴더에 `<이름>.md` 로 두고 `check-writing --profile <이름>` 으로 고른다.
`--profile` 을 주지 않으면 `doksam.md` 를 읽는다. 다른 폴더의 파일은 `--profile /경로/acme.md` 처럼 경로로 준다.

파일은 세 부분으로 쓴다. 필요한 부분만 둔다.

## 1. 사람이 읽는 규칙

`## 표기 규칙` 절에 시각 형식, 숫자 표기, 이모지 사용 여부를 글로 적는다.
에이전트는 글을 쓰기 전에 이 절을 읽는다. 검사기는 이 절을 읽지 않는다.

## 2. 내장 검사 켜고 끄기

절 이름은 `표기 검사` 로 쓴다. 표의 칸은 `검사`, `수준`, `안내` 순서다.

| 검사 이름 | 잡는 것 |
|---|---|
| `이모지` | 이모지 문자 |
| `시각 표기` | ISO 8601 시각(`T` 구분자, `+09:00` 같은 시간대) |

- 수준은 `오류`, `경고`, `끔` 가운데 하나다. 표에 없는 검사는 끈다.
- 안내는 위반을 알릴 때 보여 줄 고칠 방법이다.

ISO 8601 을 표준으로 쓰는 조직은 이렇게 적는다.

```markdown
## 표기 검사

| 검사 | 수준 | 안내 |
|---|---|---|
| 이모지 | 경고 | 글로 바꾼다 |
| 시각 표기 | 끔 | - |
```

## 3. 조직에서 자주 새는 표현

`banned-expressions.md` 와 같은 `금지`, `대체`, `검사` 표를 다른 절에 둔다.
검사기는 이 규칙을 공통 금지 표현 뒤에 이어서 적용한다. 정규식과 옵션(`경고`, `3회`) 문법도 같다.

```markdown
## acme 에서 자주 새는 표현

| 금지 | 대체 | 검사 |
|---|---|---|
| 금일 | 오늘 | `금일` |
| 익일 | 다음 날 | `익일` 경고 |
```

## 확인

```bash
bash <스킬경로>/scripts/check-writing --profile <이름> 글.md
```

수준이나 검사 이름이 틀리면 검사기가 줄 번호와 함께 알리고 종료 코드 2 로 끝난다.

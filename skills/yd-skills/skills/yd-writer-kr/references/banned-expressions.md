# 금지 표현 목록

문장을 고칠 때 이 목록과 대조한다.
왼쪽이 보이면 오른쪽으로 바꾼다.

> 명사형 종결 표는 문어체 산출물(이슈·MR·문서·공지)에만 적용한다. 채팅 MZ체의 ~함·~임은 허용한다.

`검사` 열은 Go 검사기 `scripts/check-writing` 이 읽는 정규식이다. 이 파일이 금지 표현의 유일한 원본이다.
Go 정규식(RE2)은 전후방 탐색이 없다. 경계 조건은 맨 앞 `(?<![...])`·맨 뒤 `(?![...])` 로만 적는다(#117).
`\d`·`\s`·`\b` 는 ASCII 만 본다. 한글 경계는 `(?<![가-힣])` 처럼 글자 범위로 적는다.
`-` 는 자동 판정이 어려워 사람이 보는 항목이다(예: ~의 는 대부분의 문장에 나온다).
정규식 안의 `|` 는 표 구분자와 겹치므로 `\|` 로 적는다.

검사 칸의 닫는 백틱 뒤에 옵션을 적을 수 있다(#137). 옵션이 없으면 한 번만 나와도 오류다.

- `경고`: 오류 대신 경고로 낸다. 종료 코드는 `--strict` 일 때만 1 이다.
- `3회`: 한 문장 안에서 3번 이상 나올 때만 한 건으로 낸다. 흔한 낱말은 하나만 나와도 잡으면 오탐이 많다.
- 둘을 함께 쓸 때는 `정규식` 뒤에 `경고 3회` 로 적는다.

산문 모드(`--prose`)는 소설·에세이 같은 문학 산문을 볼 때 쓴다. 피동형·중복 수식·일본어 투·영어 번역투 절만 검사한다.
나머지 절과 긴 문장 경고는 실용문 기준이라 건너뛴다(#126). 절 이름을 바꾸면 Go 검사기의 `proseSections` 도 고친다.
#137 에서 더한 절(겹말, 조사 겹침·일본어 투 보강, 늘어지는 서술어, 군더더기 낱말, 남용)은 산문 모드에서 보지 않는다.

조직마다 다른 표기 규칙(시각 형식, 이모지)과 그 조직에서 자주 새는 표현은 `profiles/<이름>.md` 에 둔다.
작성법은 `profiles/README.md` 에 있다.

## 참고 문헌

원칙과 목록은 아래 책의 지적 가운데 기계로 잡을 수 있는 것을 골라 만들었다.
책의 문장은 옮기지 않았다. 표의 예와 테스트 예문은 모두 직접 썼다.

- 이오덕, 『우리글 바로쓰기』: 일본어 투, 조사 겹침, 번역투.

## 일본어 투

| 금지 | 대체 | 검사 |
|---|---|---|
| ~적(的) | 풀어 쓰기 (예: 논리적 → 논리에 맞게) | - |
| ~의 | 생략 (예: 나의 책 → 내 책) | - |
| ~에 있어서 | ~에서, ~에게 | `(?<! 안\| 밖\| 위\| 밑\| 옆\| 곁\| 앞\| 뒤\| 속\| 곳\| 집\| 방\|운데\|아래\|근처\|주변\|사이\|자리\|폴더\|터리\|경로\|서버\|파일)에 있어서(?!는 안\|[,，])` |
| ~에 다름 아니다 | ~이다 | `에 다름 아니` |
| ~에 값하다 | ~할 만하다 | `에 값하` |
| ~에 의해 | ~가, ~때문에 | `에 의해` |
| ~에 의하면 | ~에 따르면 | `에 의하면` |
| ~하지 않으면 안 된다 | ~해야 한다 | `지 않으면 안 (된\|돼\|됩)` |
| ~해 버리다 (てしまう 직역) | ~했다 (끝남·아쉬움을 꼭 말해야 할 때만 남긴다) | `(?<!잊\|잃)(?:어\|아\|여\|해\|워\|줘\|돼\|써\|져\|쳐) ?버(?:렸\|린\|리\|려)` |

- `에 있어서`: "있다 + -어서"(존재·이유)는 번역투가 아니다. 장소 명사 뒤, 쉼표 앞, `있어서는 안` 꼴은 뺀다(#126).
  Python 호환 계층도 이 정규식을 컴파일하므로 앞 경계는 길이가 같아야 한다. 그래서 장소 명사를 끝 두 글자(`운데`·` 안`·`서버`)로 적는다.
  그 밖의 존재 용법(`책상이 거실에 있어서 좁다`)은 구별하지 못한다. 그런 줄은 `writer:allow` 로 면제한다.
- `해 버리다`: 합성어 `잊어버리다`·`잃어버리다` 는 표준어라 뺀다. 줄임꼴 `가 버렸다` 는 조사 `가` 와 겹쳐 잡지 않는다(#126).

## 조사 겹침·일본어 투 보강

이오덕이 지적한 일본어 투 가운데 `일본어 투` 절에 없던 것이다. 실용문에만 적용한다.

| 금지 | 대체 | 검사 |
|---|---|---|
| ~에의·~에서의·~으로의·~로서의 (조사 겹침) | 풀어 쓴다 (예: 서버에의 접속 → 서버 접속) | `(?<=[가-힣])(에의\|에서의\|에로의\|으로의\|로서의)(?![가-힣])` 경고 |
| ~을 요하다 | ~해야 한다, ~이 필요하다 | `[을를] 요(하\|한\|함\|합\|했)` |
| ~라 아니할 수 없다 | ~이다 | `아니할 수 없` |
| ~에 틀림없다 | ~이 분명하다, 틀림없이 ~이다 | `에 틀림없` 경고 |
| ~함에 있어 | ~할 때 | `[함음]에 있어(?=[ ,])` 경고 |
| 보다 ~한 (부사 보다) | 더 ~한 | - |

- 조사 겹침은 굳은 표현(`앞으로의 계획`)에도 걸린다. 그래서 경고로 둔다.
- 부사 `보다` 는 조사 `보다` 와 모양이 같다. 인라인 코드 뒤의 조사도 구별하지 못해 사람이 본다.

| 금지 | 대체 | 검사 |
|---|---|---|
| 검토를 하다·확인을 하다 | 검토하다·확인하다 | `(검토\|점검\|확인\|분석\|조사\|논의\|협의\|수정\|변경\|적용\|배포\|설치\|개선\|검증\|삭제\|등록)[을를] (하였\|했\|한다\|합니다\|하고\|하여\|해서\|해야\|할)` 경고 |

| ~는 바이다 | ~한다 | `는 바(이다\|입니다)` |
| ~고자 합니다 | ~하겠습니다, ~하려 한다 | `고자 (합니다\|한다\|하였\|했)` 경고 |

- `~시키다`: 남에게 하게 한다는 뜻이면 맞는 말이다. 스스로 하는 일에 붙였을 때만 고친다.
- `~의 경우`: `최악의 경우`·`만일의 경우` 는 굳은 표현이라 뺀다.

## 남용 (한 문장 안의 횟수)

하나만 나오면 문제가 아닌 낱말이다(김정선). 한 문장에 몰리면 경고한다.

| 금지 | 대체 | 검사 |
|---|---|---|
| 한 문장에 ~의 3개 이상 | 문장을 나누거나 `의` 를 뺀다 | `(?<! 회\| 주\| 논\| 협\| 합\| 정\| 동\| 문\| 거\| 강\| 편\| 결\| 심\| 질\| 토\| 유\| 임\| 고\| 호\| 예\| 창\| 건\| 상\| 의\|민주\|본주\|회주)의(?![가-힣])` 경고 3회 |
| 한 문장에 ~적 3개 이상 | 구체어로 바꾼다 (예: 효율적으로 → 10분 안에) | `[가-힣]{2,}적(?:인\|으로\|이다\|이고\|이며\|이지\|[ ,.)]\|$)` 경고 3회 |
| 한 문장에 것 3개 이상 | 가리키는 대상을 바로 쓴다 | `(?<![가-힣])것` 경고 3회 |
| 한 문장에 ~들 3개 이상 | 복수 표시는 필요한 곳에만 쓴다 | `[가-힣]들(?:이\|은\|을\|의\|에\|도\|과\|만)` 경고 3회 |
| 많은·여러·모든 ~들 | `들` 을 뺀다 (예: 여러 파일들 → 여러 파일) | `(많은\|여러\|모든\|수많은\|몇몇\|다양한\|각종) [가-힣]{1,6}들(?:이\|은\|을\|의\|에\|도\|과\|만\|[ ,.]\|$)` 경고 |

- `~의`: `회의`·`주의`·`논의`·`거의` 처럼 `의` 로 끝나는 낱말은 세지 않는다. 문장 맨 앞에 오면 한 번 센다.
- `~적`: `목적`·`실적`·`누적` 같은 두 글자 낱말은 세지 않는다. 그래서 `법적`·`인적` 도 세지 못한다.
- `~들`: `만들`·`힘들` 은 뒤에 조사가 붙지 않아 세지 않는다. `아들이` 는 한 번 센다.

| 해당 ~ | 이 ~, 그 ~ (가리키는 대상을 바로 쓴다) | - |

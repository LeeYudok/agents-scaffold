# 그림별 자료 형식

`brief.json` 의 블록 `{"type": "figure", "kind": ..., "spec": {...}}` 에 넣는 `spec` 이다. 온전한 예는 `assets/example/brief.json` 에 있다.

## `architecture` — 층별 전체 구성도

가운데에 층을 위에서 아래로 쌓는다. 왼쪽에 입력, 오른쪽에 연계 시스템, 아래에 대상 시스템과 인프라를 둔다.

| 키 | 뜻 |
|---|---|
| `boundary` | 점선 경계의 이름. 예: 행내 폐쇄망 |
| `actors` | 위쪽 사용자. `[이름, 설명]` |
| `inputs` | 왼쪽 입력. `[이름, 설명]` |
| `layers` | 가운데 층. `title`, `note`, `items`, 선택으로 `accent`, `steps` |
| `layers[].items` | 층 안 상자. `[이름, [설명 줄], 표시]`. 표시는 결정 번호 |
| `layers[].steps` | 처리 단계 이름 목록. 마지막 단계는 먹으로 채운다 |
| `systems` | 오른쪽 연계 시스템. `[이름, 줄1, 줄2, 표시]` |
| `outside` | 경계 밖 시스템 하나. `[이름, 줄1, 줄2, 표시]` |
| `target` | 대상 시스템 띠. `title`, `chips` |
| `infra` | 인프라. `[이름, 확인 필요 여부]` |

- 층은 3~4개가 알맞다. `accent` 는 한 층에만 준다.
- 층 안 상자는 2~3개, 설명은 두 줄까지다.
- 표시 번호는 그림 아래 `keys` 와 순서를 맞춘다.
- 연계 시스템이 어느 층에 붙는지 원자료에 없으면 주석에 밝힌다.

## `metro` — 노선도식 흐름도

| 키 | 뜻 |
|---|---|
| `stations` | 본선 정거장 이름. 마지막은 종착역(사람의 확인) |
| `notes` | 정거장 아래 한 줄. 키는 정거장 번호(0부터) |
| `feeders` | 왼쪽에서 모이는 지선. `[이름, 설명]` |
| `transfers` | 위에서 내려와 한 정거장에서 만나는 노선. `at`, `label`, `lines` |
| `transfers.lines` | `[이름, 설명, 뺀 이유]`. 뺀 이유가 있으면 경고색 점선 |
| `beyond` | 종착역 뒤 범위 밖 절차. `[이름, 설명]` |
| `zone` | 본선 뒤에 까는 구역 설명 |
| `flags` | 정거장 위 경고. `at`, `text` |
| `lower` | 아래 연계선. `label`, `link`, `stations` |

- 정거장은 4~6개가 알맞다.
- 환승 노선은 3개까지다.

## `compare_rows` — 행별 대비 그림

| 키 | 뜻 |
|---|---|
| `left`, `right` | `[제목, 설명]`. 왼쪽은 지금, 오른쪽은 앞으로 |
| `rows[].label` | 행 이름 |
| `rows[].left` | 왼쪽 값. 빈 문자열이면 "없음" 점선 상자 |
| `rows[].right` | 오른쪽 항목 목록 |
| `rows[].chain` | 참이면 강조색으로 채운 이어진 상자 |
| `rows[].note` | 행 아래 한 줄 |

## `gantt` — 일정 막대그림

| 키 | 뜻 |
|---|---|
| `start`, `end` | 전체 기간. `YYYY-MM-DD` |
| `tasks` | `name`, `from`, `to`, `owner`, `primary` |
| `milestones` | `[이름, 날짜]` |
| `prereqs` | 선행 조건. `[설명, 날짜]`. 같은 시간축 위에 점으로 찍는다 |

## `dumbbell` — 두 값 잇기

| 키 | 뜻 |
|---|---|
| `min`, `max`, `unit` | 축 범위와 단위 |
| `rows` | `label`, `a: [값, 출처]`, `b: [값, 출처]` |

숫자가 아닌 값의 차이는 `pairs` 블록으로 나타낸다.

## `receipt` — 내역서

고지서, 견적서, 비용 명세처럼 줄마다 금액이 있는 자료에 쓴다. 문제가 있는 줄 옆에 번호와 설명을 붙인다.

| 키 | 뜻 |
|---|---|
| `title`, `sub` | 내역서 이름과 오른쪽 작은 글 |
| `lines[].name`, `amount` | 항목과 금액 |
| `lines[].flag` | 문제가 있으면 그 이름. 줄 왼쪽에 경고색 띠가 붙는다 |
| `lines[].why`, `mark` | 설명 한 줄과 번호 |
| `total_label`, `unit` | 합계 이름과 단위. 합계는 금액을 더해 계산한다 |

## `waterfall` — 줄어드는 과정

| 키 | 뜻 |
|---|---|
| `start` | 처음 값. `label`, `value` |
| `steps` | 깎이는 단계. `label`, `value`, 선택으로 `note` |
| `end_label` | 남는 값의 이름. 값은 처음 값에서 단계를 빼서 계산한다 |
| `caption`, `unit` | 그림 아래 한 줄과 단위 |

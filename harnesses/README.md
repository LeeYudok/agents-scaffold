# 하네스 어댑터 (`harnesses/`)

중립 원천(`.claude/rules`, `.claude/agents`, `.claude/settings.json`, `skills/`)을 각 AI 코딩 하네스가 읽는 형식으로 변환·배치하는 어댑터 모음이다.

## 디렉터리 구조

| 경로 | 역할 |
|---|---|
| `common.sh` | 공통 frontmatter 파서(`claude_rule_paths`, `claude_rule_body`, `claude_fm_value`) 및 `emit_hooks` |
| `claude/adapter.sh` | Claude Code 어댑터 (`harness_apply_claude`) |
| `codex/adapter.sh` | Codex CLI 어댑터 (`emit_codex_agents`, `harness_apply_codex` → `.codex/agents/*.toml`, `.codex/hooks.json`) |
| `agy/adapter.sh` | Google Antigravity 어댑터 (`emit_agy_rules`, `emit_agy_agents`, `harness_apply_agy` → `.agents/rules/*.md`, `.agents/agents/*.md`, `.agents/hooks.json`) |

## 어댑터 인터페이스 규약

1. 각 어댑터는 `harnesses/<name>/adapter.sh` 에 두고 `harness_apply_<name>()` 함수를 제공한다.
2. 입력 전역 변수: `TARGET`(설치 대상 루트), `SRC`(스캐폴드 루트).
3. 생성한 파일에는 반드시 마커(`Generated by agents-scaffold from ...`)를 남겨, 사용자가 직접 만든 파일을 덮어쓰지 않고 `--update` 시 원본이 사라진 생성물만 안전하게 정리한다.
4. 새 하네스(예: `opencode`, `pi`)를 추가할 때는 `harnesses/<name>/adapter.sh` 를 만들고 `bin/agents-scaffold.sh` 의 `--harness` 분기에 연결한다.

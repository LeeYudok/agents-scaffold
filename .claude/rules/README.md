# rules/ — 맥락 인지 룰 가이드

AI 에이전트(Claude Code 등)가 이 레포에서 작업할 때 자동 주입되는 개발 규칙 모음.
파일 하나 = 마크다운 문서 하나.

## 작동 메커니즘

- **스코프 로드**: frontmatter `paths:`(glob 배열)가 있으면 **매칭 파일을 수정/생성할 때만** 주입된다.
- **항상 로드**: `paths:` 가 없으면 세션 시작 시 항상 로드된다 (AGENTS.md 처럼).
- 각 파일의 정확한 glob 은 **frontmatter 가 단일 진실원천** — 아래 표는 개요.

```markdown
---
paths:
  - "src/api/**/*.ts"
---
# API 규칙
- 모든 엔드포인트에 입력 검증 필수
```

## 룰 매핑

| 규칙 파일 | 스코프 (개요) | 주요 내용 |
| :--- | :--- | :--- |
| **[common.md](common.md)** | *항상 로드* | 우선순위 티어, 워크플로, 시크릿 취급, 소통 |
| **[security.md](security.md)** | 백엔드+프론트 소스, 설정 파일 | 시크릿/인증 P0, public env 시크릿 금지, 록아웃 |
| **[testing.md](testing.md)** | 테스트 파일 | 기능당 1테스트(P1), mock 단위 우선, 사용자 관점 어설션 |
| **[data.md](data.md)** | `data/` 스크립트 | 대량 데이터 스테이징 금지(P0), 인코딩 명시, OOM 방지 |
| forge 프리셋 추가 **forge.md** | *항상 로드* | forge 별 이슈/PR·MR 절차 |
| 스택 프리셋 추가 **`<stack>.md`** | 스택 소스 glob | 스택별 컨벤션 |

## 룰 작성 원칙

1. **같은 paths 로 파일 신설 금지** — 동일 스코프면 어차피 함께 로드된다(분리 이득 0). 기존 파일에 섹션으로 추가.
2. **스코프는 실작업으로 검증** — 규칙이 필요한 파일이 실제 glob 에 걸리는지 확인. 패키지 하나만 잡으면 관련 컨트롤러·매퍼에서 로드 누락된다.
3. **짧게, 근거는 이슈번호로** — 설명문 대신 규칙 한 줄 + `(#N)`. 규칙은 짧을수록 준수율이 높다.
4. **P0(절대) / P1(필수) / P2(권장) 헤더 표준** — 위반 시 처리 기준은 AGENTS.md.
5. 신설/삭제 시 **AGENTS.md 매핑과 이 표를 함께 갱신**.
6. **강제수단 태그** — 도구가 자동 검증하는 규칙에만 `[자동강제: <수단>]` 을 붙인다. **무태그 = 규율(에이전트/사람 판단)이 디폴트** — `[규율]` 명시는 "자동강제로 오인하기 쉬운" 규칙에만(예: 훅이 일부만 게이트하는 테스트 규칙). 태그 도배 금지. 부분 강제면 그 한계를 병기.
7. **사고-기원 규칙은 회고 메모리를 링크** — 규칙 옆 `(#N)` + 사고 메모리 상대링크(라벨 `[사고 메모리]` + 경로 `(../memory/파일명.md)`). 왜 지켜야 하는지 1클릭 소급. 링크는 실파일로 해석되어야 한다(placeholder 금지 — 링크 체커 `.claude/scripts/knowledge_graph.py --check` 대상).

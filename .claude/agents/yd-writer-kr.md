`yd-writer-kr` Skill 을 작업 계약의 단일 원본으로 사용한다.

역할·절차·산출물 형식은 Skill 에 있는 것을 따르고, 이 파일에 복제하지 않는다.

## 임무 계약

행동 규칙은 Skill 에 있다. 여기에는 임무를 받고 돌려주는 형식만 둔다.

**받는 것**
- 대상: 파일 경로 또는 본문
- 작업: 새로 쓰기 / 고치기
- 글 종류와 독자 (이슈·README·공지 등)

빠진 항목은 되묻지 않는다. 대상과 주변 문서로 추정하고, 추정한 값을 보고에 적는다.

**순서**
1. `scripts/check_writing.py` 로 기계 위반을 찾는다.
2. 고치기이고 키가 있으면 `scripts/upstage_proofread.py` 로 1차 교정 후보를 만든다. 비공개 문서는 보내지 않는다.
3. 후보를 원문과 문장 단위로 대조한다. 뜻·수치·이름·코드가 바뀐 곳은 원문으로 되돌린다.
4. Skill 점검표로 마무리하고 검사기를 다시 돌린다.

**돌려주는 것**
1. 결과 글. 파일 경로를 받았으면 그 파일을 고치고, 본문을 받았으면 고친 본문을 돌려준다.
2. 바꾼 내용 요약. 유형별 건수와 대표 예 한두 개 (예: 번역투 4건 — `~에 있어서` → `~에서`).
3. 마지막 검사기 출력 원문 (`오류 N건, 경고 M건` 줄 포함).
4. 확인하지 못한 사실과 추정한 입력값.

**완료 조건**
- 검사기 오류 0건. 경고가 남으면 남긴 이유를 적는다.
- 뜻·사실·코드·인용·표 값이 원문과 같다.
- 커밋·푸시하지 않는다. 부른 쪽이 결과를 보고 정한다.

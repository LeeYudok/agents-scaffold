# doksam 표기 프로필

doksam 의 표기 규칙이다. 검사기는 `--profile` 을 주지 않으면 이 파일을 읽는다.
다른 조직은 이 파일을 복사해 `<이름>.md` 로 고쳐 쓰고 `--profile <이름>` 으로 고른다. 작성법은 `README.md` 에 있다.

## 표기 규칙

- 시각: `YYYY-MM-DD HH:MM:SS.mmm`(KST). ISO 8601 의 `T`·`+09:00` 은 쓰지 않는다. 날짜만이면 `YYYY-MM-DD`.
- 이모지를 아이콘이나 장식으로 쓰지 않는다.
- 숫자는 천 단위 쉼표를 찍는다(610,110건). 비율은 분자·분모를 같이 쓴다(7/30, 23%).

## 표기 검사

| 검사 | 수준 | 안내 |
|---|---|---|
| 이모지 | 오류 | Phosphor 아이콘이나 글로 바꾼다 |
| 시각 표기 | 오류 | YYYY-MM-DD HH:MM:SS.mmm (KST) |

천 단위 쉼표는 검사기가 보지 않는다. 사람이 점검표로 본다.

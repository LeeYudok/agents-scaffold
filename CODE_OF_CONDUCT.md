# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep criticism about the work and not the person, and no
harassment of any kind. This applies to issues, pull requests, reviews and any other project space.

To report a problem, contact the maintainer privately through
[GitHub's private reporting](https://github.com/LeeYudok/agents-scaffold/security/advisories/new) or the
contact on the maintainer's GitHub profile. Reports are handled confidentially.

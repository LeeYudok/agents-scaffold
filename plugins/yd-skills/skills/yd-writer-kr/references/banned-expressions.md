# 금지 표현 목록

문장을 고칠 때 이 목록과 대조한다.
왼쪽이 보이면 오른쪽으로 바꾼다.

> 명사형 종결 표는 문어체 산출물(이슈·MR·문서·공지)에만 적용한다. 채팅 MZ체의 ~함·~임은 허용한다.

`검사` 열은 `scripts/check_writing.py` 가 읽는 정규식이다. 이 파일이 금지 표현의 유일한 원본이다.
`-` 는 자동 판정이 어려워 사람이 보는 항목이다(예: ~의 는 대부분의 문장에 나온다).
정규식 안의 `|` 는 표 구분자와 겹치므로 `\|` 로 적는다.

## 명사형 종결 (문어체 산출물만)

| 금지 | 대체 | 검사 |
|---|---|---|
| ~함 | ~한다 | `(?<![포협])함[.)]?$` |
| ~임 | ~이다 | - |
| ~됨 | ~된다 | `됨[.)]?$` |
| ~있음 | ~있다 | `있음[.)]?$` |
| ~필요함 | ~필요하다 | `필요함` |

## 일본어 투

| 금지 | 대체 | 검사 |
|---|---|---|
| ~적(的) | 풀어 쓰기 (예: 논리적 → 논리에 맞게) | - |
| ~의 | 생략 (예: 나의 책 → 내 책) | - |
| ~에 있어서 | ~에서, ~에게 | `에 있어서` |

| ~에 의해 | ~가, ~때문에 | `에 의해` |
| ~에 의하면 | ~에 따르면 | `에 의하면` |

## doksam 에서 자주 새는 표현

| 금지 | 대체 | 검사 |
|---|---|---|
| ~이슈가 발생하다 | 증상을 직접 쓴다 (실패한다, 멈춘다) | `(이슈\|문제\|오류\|에러)가 발생` |
| ~관련하여 | ~의, ~에서 (또는 삭제) | `관련(하여\|해서)` |
| ~을 진행하다 | 구체 동사 (돌린다, 고친다, 옮긴다) | `[을를] 진행(하\|했\|한\|합)` |
| ~이 완료되었습니다 | ~했다 (채팅이면 ~했어요, 완료 ㅇㅇ) | `완료되었(습니다\|다)` |
| ~을 통해 확인되었다 | ~로 확인했다 | `통해 확인되었` |
| 정상적으로 | (삭제하고 결과를 쓴다) | `정상적으로` |
| 성공적으로 | (삭제) | `성공적으로` |

## 과장·모호

근거가 있는 것만 넣는다. 각 행의 근거는 아래 표 다음에 적는다.

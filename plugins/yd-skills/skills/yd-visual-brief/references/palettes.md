# 팔레트

색은 `assets/palettes.json` 에 있다. `brief.json` 의 `palette` 에 이름을 적는다. 적지 않으면 `ink-cobalt` 다.

## 역할

| 역할 | 쓰는 곳 |
|---|---|
| `paper` | 문서 바탕. 순백보다 살짝 물든 색이 눈이 편하다 |
| `ink` | 본문 글자, 굵은 선, 종착역. 순흑보다 살짝 색이 도는 검정 |
| `accent` | 주인공. 본선, 우리가 만드는 층, 바꾼 뒤 |
| `signal` | 문서끼리 안 맞는 곳, 정해야 하는 것, 확인이 필요한 것 |
| `muted` | 보조 글자, 지금 있는 것, 범위 밖 |
| `line` | 가는 구분선, 상자 테두리 |
| `soft` | 상자 안쪽 옅은 바탕 |
| `tint` | 강조색을 아주 옅게 푼 바탕. 주인공 영역을 깔 때 |

## 고르는 기준

- 내용의 온도에 맞춘다. 기술·금융은 차가운 `ink-cobalt`, 사람·운영은 따뜻한 `forest-terracotta`, 서비스 소개는 밝은 `sea-coral`.
- 한 문서에는 팔레트 하나만 쓴다.
- 독자의 조직 색이 있으면 그 색을 강조색으로 삼아 새 팔레트를 만든다.

## 새 팔레트를 만들 때

1. 강조색을 먼저 정한다. 바탕 위에서 대비 4.5 이상이어야 한다.
2. 경고색은 강조색과 색상 차가 60도 이상인 따뜻한 색으로 고른다. 강조색이 따뜻하면 경고색을 더 붉게 잡는다.
3. 바탕과 먹에는 강조색 쪽 기운을 조금 섞는다. 푸른 강조색이면 먹도 푸른 기가 도는 검정으로 잡는다.
4. `muted`, `line`, `soft` 는 채도를 거의 뺀 회색으로 둔다.
5. `tint` 는 강조색을 바탕에 5~8% 섞은 색이다.
6. `assets/palettes.json` 에 더하고 `python3 scripts/check_brief.py --palettes` 로 확인한다.

## 하지 않는 것

- 무지개색 범주 구분. 범주는 위치와 제목으로 나눈다.
- 신호등 색(초록·노랑·빨강)으로 상태 표시. 먹으로 채움, 테두리만, 경고색 세 단계로 나타낸다.
- 그라데이션과 그림자.
